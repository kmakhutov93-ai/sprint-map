# Изменения в Sprint Map

## Подготовка

Нужен Node.js 24 или новее. Установите зафиксированные инструменты разработки:

```sh
npm ci --ignore-scripts
npm run check
```

Приложение запускается командой `npm start` без установки runtime-зависимостей.
Описание модели и её ограничений — [docs/design.md](docs/design.md).

## Авторство коммитов

Перед первым коммитом настройте **своё** имя и подтверждённый адрес GitHub
или noreply-адрес из настроек своего аккаунта. Настройки задаются только
для текущего репозитория:

```sh
git config --local user.name "Ваше имя"
git config --local user.email "ВАШ_ID+ВАШ_LOGIN@users.noreply.github.com"
git var GIT_AUTHOR_IDENT
```

Замените значения своими. Правильный адрес см. в
[GitHub Settings → Emails](https://github.com/settings/emails).
Владение репозиторием и авторство его коммитов — разные сведения.
Не меняйте авторов и даты чужой или совместной истории ради отображения профиля.

## Порядок работы

1. Создайте ветку для одной задачи.
2. Для ошибки сначала воспроизведите её тестом и проверьте ожидаемое падение.
3. Внесите минимальную правку; не меняйте ограничения модели случайно.
4. Выполните `npm run check` и проверьте затронутый сценарий в браузере.
5. В коммите опишите фактическое изменение и участие AI, если он использовался.

Тесты интерфейса работают через LinkeDOM. Загрузку файлов, отображение CSS
и работу на узком экране дополнительно проверяют в настоящем браузере.

Перед демонстрацией сохраняйте изменения форм соответствующей кнопкой,
а переносимую копию плана — через «Экспорт JSON».
