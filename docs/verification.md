# Проверка от 20 сентября 2026 года

Исходная версия: `72d047635634bb41b20fd4afca4305ab29a9f683`.
Проверяемое исправление: `b1d8bcd575fe2e0bc4dec08cd4f27d894780d876`.
Среда: macOS, Node.js 24.13.0, npm 11.6.2.

## Исправленная ошибка

1. Откройте редактирование участника без назначенных задач и удалите его.
2. В форме добавления введите нового участника и сохраните.
3. Аналогично откройте редактирование задачи без зависимых задач, удалите её
   и добавьте новую.

До исправления форма выглядела как добавление, но сохраняла ID удалённой
записи: новый участник или задача не появлялись. Теперь редактор сбрасывает
отсутствующий ID после успешного изменения проекта.
