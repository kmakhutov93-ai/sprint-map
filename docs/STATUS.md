# Состояние Sprint Map

Дата: 20 сентября 2026 года.

Первая локальная версия: команда и доступность, задачи и зависимости,
расчёт сроков, объяснение ожидания, исходный план и один сценарий,
сокращение дополнительного объёма, импорт/экспорт и сохранение в браузере.
Правила расчёта и ограничения записаны в [design.md](design.md).

## Сохранённый контекст

Аккаунт сопровождения: `kmakhutov93-ai`.
Целевой публичный репозиторий: https://github.com/kmakhutov93-ai/sprint-map.
Ветка публикации — `main`; разработка ведётся в отдельных ветках задач.
Код других проектов и реальные данные команды не использовались.
Все имена и задачи демонстрации вымышлены.

Запуск: `npm start`, адрес
http://127.0.0.1:4174. Инструкция и минутный сценарий демонстрации — в README.
Для продолжения работы нужны этот репозиторий и экспорт JSON, если план менялся
в браузере: localStorage не входит в файлы исходного кода.

Оформление обновлено в ветке `feat/montserrat-liquid-glass`: локальный Montserrat
с лицензией OFL, веб-стили в духе Liquid Glass, варианты для уменьшения
прозрачности и повышенного контраста. Модель и расчёт расписания не изменены.

## Проверка

Проверены расчёты, ограничения модели, хранение, основные действия интерфейса
и HTTP-сервер. `npm run check` прошёл: ESLint, Prettier и 45 тестов.
Это результат исходной версии от 19 сентября. Проверка 20 сентября выявила
ошибку добавления после удаления редактируемой записи; она исправлена, добавлены
два регрессионных теста. Результат и воспроизводимые шаги —
[verification.md](verification.md).

Итоговая проверка 20 сентября: `npm run check` — ESLint, Prettier и 47 тестов.

В настоящем браузере проверены демосценарий, сохранение после перезагрузки,
скачивание и обратный импорт JSON, обычный экран и ширина 390 px.
Физический телефон и другие браузеры не проверялись.

Проект использует обычный алгоритм распределения часов, без AI-модели.
Готовность портфолио к конкретному конкурсу и правила участия требуют отдельной
проверки; качество проекта не гарантирует прохождение отбора.
